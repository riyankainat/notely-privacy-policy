Privacy Policy for Notely

Last Updated: September 25, 2026
Privacy at a glance:

Notely is a note-taking application designed to allow users to create, edit, organize, and delete notes on their Android devices.

Note content and images added to notes are stored locally on the user's device. Notely does not operate a cloud service for storing users' notes.

1. About This Privacy Policy

This Privacy Policy explains how Notely handles information when you use the application.

By using Notely, you acknowledge that you have read and understood this Privacy Policy.

2. Information We Collect

Notely does not require users to create an account or provide personal information such as a name, email address, or phone number to use its core note-taking functionality.

Notely does not intentionally collect personal information through its own servers.

The information created within the application may include:

  • Note titles
  • Note text and descriptions
  • Note categories
  • Text formatting information
  • Images selected by the user
  • Information required to display and manage notes

3. How Notes Are Stored

Notes created in Notely are stored locally on the user's Android device using application-local storage.

The application may store note information such as titles, descriptions, categories, formatting data, image references, and content structure locally so that notes can be displayed and edited.

Local storage:

Note content is not intentionally uploaded to a Notely-operated cloud server.

4. Images and Photos

Notely allows users to select images from their device and insert them into notes.

When an image is selected, the application stores a local copy/reference required for displaying that image inside the corresponding note.

Notely does not intentionally upload selected images to a Notely-operated server.

Users control which images they choose to add to their notes.

5. How Information Is Used

Information stored by the application is used to provide the functionality of Notely.

This includes:

  • Creating notes
  • Editing notes
  • Automatically saving note changes
  • Displaying saved notes
  • Displaying images within notes
  • Organizing notes using categories
  • Applying text formatting
  • Deleting notes

6. Data Sharing

Notely does not sell, rent, or intentionally share users' note content or locally stored images with third parties.

Notely does not operate a server through which users' notes are routinely transmitted or stored.

If this changes in a future version of the application, this Privacy Policy will be updated accordingly.

7. Advertising

Notely does not currently display advertisements or use advertising SDKs, provided that no advertising SDK is included in the version distributed through Google Play.

8. Analytics and Tracking

Notely does not currently use its own analytics or tracking system to collect information about users' activity.

This statement applies to the application and third-party SDKs included in the distributed version.

9. Third-Party Services

Notely does not currently use third-party services to store users' notes or images.

If third-party SDKs or services are added in future versions and those services collect or process user data, this Privacy Policy and the Google Play Data Safety information will be updated as required.

10. Data Security

Notely stores note content locally on the user's Android device.

Users are responsible for maintaining the security of their Android device, including any device lock, PIN, password, or biometric protection.

While reasonable measures are used within the application to store and manage local application data, no method of electronic storage can be guaranteed to be completely secure.

11. Data Retention

Note information is retained on the device for as long as it remains stored by the user within the application.

Users can delete individual notes using the deletion functionality provided by Notely.

12. Data Deletion

Users can delete notes directly through the application.

Because Notely stores its core note data locally, users can manage and remove their locally stored note content through the application's available deletion features and Android's application-data management.

Uninstalling the application may remove its locally stored application data according to Android's operating-system behavior.

13. Children's Privacy

Notely does not knowingly collect personal information from children through its own servers.

The application does not require users to create an account or submit personal information to use its core note-taking functionality.

14. Permissions

Notely may request access to functionality required for features such as selecting images from the user's device.

Any permission requested by the application is intended to support a specific application feature.

15. Changes to This Privacy Policy

We may update this Privacy Policy when the application, its data practices, or applicable requirements change.

When changes are made, the "Last Updated" date at the top of this Privacy Policy will be updated.

Users are encouraged to review this Privacy Policy periodically.
